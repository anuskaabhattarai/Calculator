# Calculator

## Description
This is a simple calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations like addition, subtraction, multiplication, and division.

## Features
* Basic operations (+, -, *, /)
* Clear button
* Responsive layout
* Interactive UI

## Technologies Used
* HTML
* CSS
* JavaScript

## What I Learned
* Handling user input using JavaScript
* DOM manipulation
* Event handling
* Writing basic logic for calculations

## How to Run
1. Download or clone the repository
2. Open index.html in a browser

## Project Structure
* index.html
* style.css
* script.js
